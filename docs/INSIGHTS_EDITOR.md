# Editor de Insights

El editor guiado se encuentra en `/portal/abogado/articulos/nuevo`. No acepta HTML libre. El contenido se guarda como bloques tipados (`ArticleBlock`) y también conserva una representación plana prudente para compatibilidad.

Se admiten encabezados, párrafos, listas, citas, llamadas, notas y conclusiones. El autor deriva de la sesión; no puede escribirse manualmente dentro del contenido. El editor permite seleccionar coautores activos y asociar una imagen destacada que pasa por el pipeline seguro de medios. El asociado guarda borradores y los envía a revisión. Socios y ADMIN pueden aprobar o publicar según las políticas centrales.
